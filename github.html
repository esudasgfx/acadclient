GitHub & Codespaces

Repositories, Visibility, Cloud Development & File Management
What is this? GitHub is a platform for version control and collaboration. GitHub Codespaces gives you a complete development environment in the cloud – no need to install Python on your local machine!

We'll cover repository visibility, setting up Codespaces, installing Python libraries, and uploading/ managing files.

1. What is GitHub?

GitHub is a platform for storing, managing, and collaborating on code. It uses Git (a version control system) to track changes to your files.

  • Repository (Repo): A folder that contains all your project files (code, data, documentation).
  • Version Control: Tracks every change made to your files, so you can go back to previous versions if needed.
  • Collaboration: Multiple people can work on the same project simultaneously.
  • Cloud Storage: Your code is stored safely in the cloud, accessible from anywhere.
Why GitHub? It's the industry standard for developers. Learning GitHub is as important as learning Python!

2. Repository Visibility – Public vs Private

When you create a repository on GitHub, you choose its visibility. This determines who can see and access your code.

Visibility Who Can See It Use Case Badge
Public Anyone on the internet Open-source projects, portfolios, learning examples PUBLIC
Private Only you and people you explicitly invite (collaborators) Company code, sensitive projects, work-in-progress PRIVATE

How to Check or Change Visibility

  • Go to your repository on GitHub.
  • Click on Settings (top-right tab).
  • Scroll down to the Danger Zone section.
  • Look for Change repository visibility.
  • Select Public or Private and confirm.
Important: Once a repository is public, anyone can see your code. Always use Private for company or sensitive projects.

3. GitHub Codespaces – Your Cloud IDE

GitHub Codespaces is a cloud-based development environment. It gives you a fully configured IDE (like VS Code) in your browser – with Python pre-installed!

  • No local installation required – just a browser and internet connection.
  • Pre-configured environment – Python, pip, git, and essential tools are already set up.
  • Seamless integration – directly connected to your GitHub repository.
  • Accessible anywhere – code from any device.

How to Launch Codespaces

  1. Open your repository on GitHub.
  2. Click the Code button (green).
  3. Select the Codespaces tab.
  4. Click Create codespace on main (or your preferred branch).
  5. Wait for the environment to spin up (takes 1–2 minutes).
  6. You'll see a fully functional VS Code editor in your browser!
Tip: Your Codespace is persistent – you can stop and restart it, and your files will still be there.

4. Setting Up Your Environment – Installing Dependencies

When you open a Codespace, Python is already installed. However, you may need additional libraries (like pandas and openpyxl) for data processing.

Using the Terminal

The terminal is available at the bottom of the Codespace window. You can run commands just like on your local machine.

Installing Python Packages

# Install pandas (for data manipulation)
pip install pandas

# Install openpyxl (to read/write Excel files)
pip install openpyxl
Expected Output (success):
Successfully installed pandas 2.0.3
Successfully installed openpyxl 3.1.2
Tip: You can also create a requirements.txt file with all your dependencies and run pip install -r requirements.txt to install everything at once.

5. Working with Files – Uploading & Managing

In Codespaces, you can easily upload files (like Excel spreadsheets), create new folders, and organize your project.

Uploading Files (e.g., .xlsx)

  1. In the Codespace file explorer (left panel), click on the Explorer icon (two sheets of paper).
  2. You can drag and drop your Excel file directly into the file explorer.
  3. Alternatively, click the ... (More Actions) menu and select Upload.
  4. Your file will appear in the project folder, ready to be used in your Python code.
Note: Excel files (.xlsx) can be read using pandas.read_excel() after installing openpyxl.

Adding Files and Folders

  • New Folder: Click the ... (More Actions) menu in the file explorer and select New Folder. Name it (e.g., data, scripts).
  • New File: Click the ... (More Actions) menu and select New File. Name it (e.g., analyze.py).
  • Rename / Delete: Right-click on any file or folder to rename, delete, or copy it.
# Example file structure in Codespaces:
my-project/
├── data/
│ └── projects.xlsx # uploaded Excel file
├── scripts/
│ └── analyze.py # your Python script
└── requirements.txt # dependencies
Pro Tip: Keep your data files in a separate folder (like data/) and your Python scripts in scripts/ to keep your project organized.

6. Saving Changes – Commit & Push

All changes you make in Codespaces are automatically saved. However, to save them permanently to your GitHub repository, you need to commit and push.

  1. In the left panel, click the Source Control icon (branch with a number).
  2. Enter a message describing your changes (e.g., "Added Excel upload logic").
  3. Click the Commit button (✓) to commit your changes locally.
  4. Click the Sync Changes button (or Push) to upload your changes to GitHub.
Tip: Committing regularly helps you keep track of your work and revert to previous versions if needed.
