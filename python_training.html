Python Basics

Step‑by‑step guide  ·  Syntax, Variables & Data Types
Step 1

What is Python?

Python is a high‑level, interpreted programming language known for its readability and versatility. It is widely used in web development, data science, automation, and more.

Key philosophy: “Readability counts.” Python uses indentation (whitespace) to define code blocks, making the code clean and easy to follow.
Step 2

Syntax & Basic Rules

Python syntax is minimal and intuitive. Here are the core rules to remember:

  • Indentation: Use 4 spaces (or a tab) to indicate blocks of code. No curly braces { } are needed.
  • Comments: Start with # for single‑line comments. Multi‑line comments use triple quotes """ ... """.
  • Case sensitivity: myVar and myvar are different.
  • Statements: Each line is a statement. Semicolons are optional but not recommended.
# This is a comment
if 5 > 2:           # colon indicates start of block
    print("Five is greater than two")  # indentation is mandatory
Step 3

Variables – Storing Data

Variables are names that refer to values. In Python, you don't need to declare a type – the interpreter infers it at runtime (dynamic typing).

  • Naming rules: Start with a letter or underscore, followed by letters, digits, or underscores. Case‑sensitive.
  • Assignment: Use the = operator.
  • Multiple assignment: a, b = 1, 2
# Simple assignment
name = "Alice"
age = 30
is_student = False

# Multiple assignment
x, y, z = 10, 20, 30

# Reassign any type
age = "thirty"   # now age is a string – perfectly valid
Dynamic typing is flexible, but be mindful of type consistency in operations to avoid runtime errors.
Step 4

Data Types – The Building Blocks

Python has several built‑in data types. Here are the most common ones you'll use:

Category Type Example Use case
Numeric int, float, complex 42, 3.14, 2+3j Counts, measurements, scientific
Text str "Hello", 'World' Names, messages, file content
Boolean bool True, False Conditions, flags, comparisons
Sequence list, tuple, range [1,2,3], (4,5), range(5) Ordered collections, immutable (tuple)
Mapping dict {"key": "value"} Key‑value pairs, configurations
Set set, frozenset {1,2,3} Unique items, mathematical operations
None NoneType None Absence of a value, null placeholder
# Examples of each type
age = 25                         # int
price = 19.99                        # float
name = "Python"                       # str
is_ready = True                         # bool
colors = ["red", "green", "blue"]   # list
coords = (10, 20)                 # tuple
person = {"name": "Bob", "age": 30}  # dict
unique = {1, 2, 3}                 # set
empty = None                         # NoneType
Step 5

Type Conversion (Casting)

You can convert between types using built‑in functions: int(), float(), str(), bool(), list(), tuple(), etc.

# Convert string to integer
num_str = "123"
num_int = int(num_str)   # 123 (int)

# Convert integer to float
num_float = float(num_int)   # 123.0 (float)

# Convert number to string
text = str(num_int) + " apples"   # "123 apples"

# List to tuple
my_list = [1, 2, 3]
my_tuple = tuple(my_list)   # (1, 2, 3)
Caution: Not all conversions are possible. For example, int("hello") raises a ValueError. Always validate or use try/except.
Step 6

Basic Operators

Python supports a rich set of operators to perform computations and comparisons.

  • Arithmetic: +, -, *, /, // (floor), % (modulus), ** (exponent).
  • Comparison: ==, !=, >, <, >=, <= (return bool).
  • Logical: and, or, not.
  • Assignment: =, +=, -=, etc.
# Arithmetic
result = 10 + 3 * 2                # 16 (multiplication first)
power = 2 ** 4                   # 16
floor_div = 17 // 5               # 3 (integer division)

# Comparison & Logical
age = 22
is_adult = age >= 18               # True
can_vote = is_adult and age < 100   # True
Step 7

Basic Input / Output

Interacting with the user is easy with print() for output and input() for reading from the console.

# Output
print("Hello, World!")
name = "Alice"
print(f"Welcome, {name}!")   # f‑string formatting

# Input (always returns a string)
user_input = input("Enter your age: ")
age = int(user_input)   # convert to int for calculations
print(f"Next year you'll be {age + 1}")
Remember: input() always returns a str. Cast it explicitly if you need a different type.
Step 8

Putting It All Together

Here's a small program that uses variables, data types, type conversion, and input/output in a practical way.

# Simple shopping calculator
# Ask for item name and price
item = input("Enter item name: ")
price_str = input("Enter price: ")
quantity_str = input("Enter quantity: ")

# Convert to appropriate types
price = float(price_str)
quantity = int(quantity_str)

total = price * quantity

# Display result with formatting
print(f"Item: {item}")
print(f"Total cost: ${total:.2f}")   # two decimal places
