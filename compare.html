Schedule Detective

Compare two Primavera task lists – find what changed.  ·  P6 Themed
Why this matters: In Primavera P6, you constantly compare baselines, current schedules, or weekly updates. This Python script does exactly that – finds added, removed, and changed tasks.

Time: 5–10 minutes  |  Tool: OneCompiler (no installation)

v2_dict = {task["id"]: task for task in v2_tasks}

Extension Challenges

Finish early? Try these extra challenges:

Challenge A: Add a New Task
Add a new task to v1_tasks or v2_tasks and see how the output changes.

Example: Add {"id": "T-106", "name": "Painting", "duration": 2.0, "status": "Open"} to V2.
Challenge B: Calculate Duration Change (Advanced)
Calculate the net change in total duration between V1 and V2.

How:
  • Loop through tasks that exist in both versions.
  • Calculate diff = v2["duration"] - v1["duration"].
  • Add all differences to get the net change.
  • Print: "Net Duration Change: +1.0 days" or "-2.0 days".

Why it's useful: This tells you if your overall project schedule got longer or shorter!
