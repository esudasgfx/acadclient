Primavera P6 REST API

Understanding Base URL, Methods, Headers, Authentication & Query Parameters
What is this? The Primavera P6 REST API allows you to interact with P6 programmatically – read projects, create tasks, update schedules, and more – using HTTP requests.

We'll explore Login (POST) and Read Projects (GET) as examples.

1. The Base URL

Every API request starts with a Base URL. This is the root address of the P6 REST API server.

https://primavera.iges.in:18206/p6ws/restapi/
  • https:// – The protocol (secure HTTP).
  • primavera.iges.in – The server hostname.
  • :18206 – The port number (optional, but required here).
  • /p6ws/restapi/ – The API endpoint path.

Different methods (also called endpoints) are appended to this base URL.

2. HTTP Methods – What They Do

HTTP methods (also called verbs) tell the server what action you want to perform.

Method Purpose In P6 Context Example
GET Read / Retrieve data Get list of projects, tasks, resources /project
POST Create new data Login, create a project, add a task /login (authentication)
PUT Update / Replace existing data Update project details, task status /project/{id}
DELETE Remove data Delete a project or task /project/{id}
Note: Some APIs also use POST for updates when PUT is not fully supported. Always check the API documentation.

3. Headers – Metadata for the Request

Headers provide additional information about the request, such as authentication, content type, and expected response format.

Header Purpose Example Value
accept What format you want the response in application/json or */*
username P6 username (for login) your-username
password P6 password (for login) your-password
Content-Type Format of the data you are sending (for POST/PUT) application/json
Authorization Token or credentials (after login) Bearer <token>
Important: After a successful login, the API may return a session token or cookie. This must be included in subsequent requests for authentication.

4. Authentication – Login (POST)

The /login method is used to authenticate your username and password with the P6 server.

URL Structure

https://primavera.iges.in:18206/p6ws/restapi/login?DatabaseName=dbname
  • /login – The method (endpoint) for authentication.
  • ?DatabaseName=dbname – A query parameter specifying which P6 database to connect to.

The cURL Command

curl -X POST "https://primavera.iges.in:18206/p6ws/restapi/login?DatabaseName=dbname" \
    -H "accept: */*" \
    -H "username: your-username" \
    -H "password: your-password"

Breaking It Down

  • -X POST – The HTTP method (create/authenticate).
  • -H "accept: */*" – Accept any response format.
  • -H "username: your-username" – Username header.
  • -H "password: your-password" – Password header.
Response:
{"message":"Login successful."}
Success! This means you are authenticated and can now make other API calls. The server may return a session cookie or token for subsequent requests.

5. Read Projects (GET)

The /project method returns a list of projects. You can filter and sort the results using query parameters.

URL Structure

https://primavera.iges.in:18206/p6ws/restapi/project?Fields=Name%2CObjectId%2CDescription%2CStartDate&OrderBy=ObjectId%20desc
  • /project – The method (endpoint) for projects.
  • ?Fields=... – Query parameter specifying which fields to return.
  • &OrderBy=... – Query parameter for sorting results.

The cURL Command

curl -X GET "https://primavera.iges.in:18206/p6ws/restapi/project?Fields=Name%2CObjectId%2CDescription%2CStartDate&OrderBy=ObjectId%20desc" \
    -H "accept: application/json"

Breaking Down the Query Parameters

Parameter Purpose Example
Fields Specifies which fields (columns) to return Name,ObjectId,Description,StartDate
OrderBy Sort the results by a field ObjectId desc (descending order)
Filter (Optional) Filter results (e.g., by status) Status eq 'Active'
Top (Optional) Limit number of results 10
Skip (Optional) Pagination – skip N results 20
URL Encoding: In the URL, %2C is the encoded version of a comma (,), and %20 is a space. This is because URLs cannot contain certain special characters.

Breaking It Down

  • -X GET – The HTTP method (read).
  • -H "accept: application/json" – Ask for JSON response format.
  • Query Parameters (after ?):
    • Fields – Tells P6 which data fields to return (e.g., Name, ObjectId).
    • OrderBy – Sorts the results (e.g., by ObjectId in descending order).
Expected Response (JSON):
{
  "Project": [
    {
      "Name": "Metro Rail Phase 2",
      "ObjectId": 1001,
      "Description": "New metro line construction",
      "StartDate": "2026-01-01"
    },
    { ... more projects ... }
  ]
}

6. Summary – What We Learned

Concept Explanation P6 Example
Base URL The root address of the API server https://primavera.iges.in:18206/p6ws/restapi/
Method / Endpoint The specific API resource you want to interact with /login, /project, /task
HTTP Method The action to perform (GET, POST, PUT, DELETE) POST to login, GET to read projects
Headers Metadata like authentication, accept format username, password, accept
Query Parameters Filter, sort, or limit the results Fields, OrderBy
Response Schema The structure of the data returned by the API JSON format (different for each method)

7. What's Next?

Now that you understand the basics of calling the P6 REST API, you can:

  • Use Python to call these APIs – using the requests library.
  • Explore other methods – /task, /resource, /wbs.
  • Combine API calls – e.g., get projects, then get tasks for a specific project.
  • Automate P6 reporting – generate schedules, dashboards, or update task status.
Tip: Use tools like Postman or the browser's Developer Console (Network tab) to inspect API requests and responses.
