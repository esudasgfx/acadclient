Project & WBS Dictionary

Goal: Store a Project with WBS details using a Python dictionary.

Step 1: Type this code. Notice how we use a dict (curly braces) to store structured data.

# P6 Exercise 1: Project & WBS Definition
project = {
    "name": "Metro Rail Phase 2",
    "id": "P-1001",
    "wbs": {
        "1.1": "Civil Works",
        "1.2": "Track Laying",
        "1.3": "Station Electrification"
    }
}

# Print project details
print("Project Name:", project["name"])
print("WBS Elements:")
for code, name in project["wbs"].items():

03

% Complete & Remaining Duration

Goal: Calculate remaining duration based on % Complete. This is core P6 logic.

Step 1: Type this code. We calculate remaining_duration.

# P6 Exercise 3: Remaining Duration Calculator
tasks = [
    {"id": "T-201", "name": "Excavation", "duration": 10.0, "pct_complete": 100},
    {"id": "T-202", "name": "Piling", "duration": 6.0, "pct_complete": 50},
    {"id": "T-203", "name": "Concrete Deck", "duration": 8.0, "pct_complete": 0}
]

for task in tasks:
    remaining = task["duration"] * (1 - task["pct_complete"] / 100)
    print(f"{task['id']}: {task['pct_complete']}% done, Remaining: {remaining:.1f} days")
Expected output:
T-201: 100% done, Remaining: 0.0 days
T-202: 50% done, Remaining: 3.0 days
T-203: 0% done, Remaining: 8.0 days
P6 Insight: In Primavera, Remaining Duration = Original Duration * (1 - % Complete). This is exactly what we just coded!

Resource Assignments & Cost Rollup

Goal: Loop through resources assigned to a task and calculate total assignment cost.

Step 1: Type this code. This simulates the P6 Resource Assignment table.

# P6 Exercise 4: Resource Cost Rollup
task_resources = [
    {"resource_name": "Crane Operator", "rate": 150.0, "hours": 40},
    {"resource_name": "Steel Fitter", "rate": 120.0, "hours": 80},
    {"resource_name": "Supervisor", "rate": 200.0, "hours": 20}
]

total_cost = 0
for res in task_resources:
    cost = res["rate"] * res["hours"]
    total_cost = total_cost + cost
    print(f"{res['resource_name']}: ${cost:,.2f}")

print("-------------------------")
print(f"Total Assignment Cost: ${total_cost:,.2f}")
Expected output:
Crane Operator: $6,000.00
Steel Fitter: $9,600.00
Supervisor: $4,000.00
-------------------------
Total Assignment Cost: $19,600.00

Mini‑Project – P6 Project Dashboard

Goal: Combine everything to build a summary dashboard that counts tasks by status and calculates planned vs actual.

Step 1: Type this complete program. This is like a lightweight P6 Activities report.

# P6 Exercise 5: Project Dashboard
project_activities = [
    {"id": "A-001", "name": "Mobilization", "status": "Completed", "planned_days": 2, "actual_days": 3},
    {"id": "A-002", "name": "Excavation", "status": "InProgress", "planned_days": 5, "actual_days": 4},
    {"id": "A-003", "name": "Foundation", "status": "Open", "planned_days": 8, "actual_days": 0},
    {"id": "A-004", "name": "Steel Fixing", "status": "Open", "planned_days": 6, "actual_days": 0},
    {"id": "A-005", "name": "Concrete Pour", "status": "InProgress", "planned_days": 3, "actual_days": 2}
]

# Counters
open_count = 0
inprog_count = 0
comp_count = 0
total_planned = 0
total_actual = 0

# Loop through activities
for act in project_activities:
    if act["status"] == "Open":
        open_count += 1
    elif act["status"] == "InProgress":
        inprog_count += 1
    else:
        comp_count += 1
    total_planned += act["planned_days"]
    total_actual += act["actual_days"]

# Print Dashboard
print("========== PROJECT DASHBOARD ==========")
print(f"Total Activities: {len(project_activities)}")
print(f" - Open : {open_count}")
print(f" - InProgress : {inprog_count}")
print(f" - Completed : {comp_count}")
print("--------------------------------------")
print(f"Total Planned Days: {total_planned}")
print(f"Total Actual Days : {total_actual}")

if total_actual > total_planned:
    print("⚠️ Project is OVER budget on days!")
else:
    print("✅ Project is ON or UNDER budget.")
Expected output:
========== PROJECT DASHBOARD ==========
Total Activities: 5
  - Open : 2
  - InProgress : 2
  - Completed : 1
--------------------------------------
Total Planned Days: 24
Total Actual Days : 9
✅ Project is ON or UNDER budget.
P6 Insight: This is exactly how Primavera calculates project rollups – looping through activities, summing planned vs actual, and classifying by status.
